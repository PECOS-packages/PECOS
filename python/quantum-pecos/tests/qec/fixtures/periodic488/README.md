# Independent periodic 4.8.8 reference fixtures

Generated by the unmodified author release for Noah Shutty,
[*Denser Planar Color Codes*, arXiv:2609.21376v3](https://arxiv.org/abs/2609.21376v3),
[Zenodo source DOI 10.5281/zenodo.22820614](https://doi.org/10.5281/zenodo.22820614).
The release is Apache-2.0; the selected unchanged code, LICENSE, NOTICE, source
paths, and hashes are under `src/pecos/qec/color/_shutty_torus488/`.

The 12 circuit fixtures cover d=4/8/12 × X/Z × one/three rounds. They were
constructed using the external author's `src/denser_codes.py`, not the PECOS
adapter or its vendored module path:

```python
circuit = denser_codes.build_memory(
    "torus_488", distance, basis, rounds=rounds, gate_set="cnot",
)
```

Geometry fixtures use the author's `_torus488_cnot.geometry.build_geometry(d)`.
`sha256.json` records all 27 hashes. Generation used Stim 1.15.0; the paper pins
1.16.0, so these are reconstruction oracles, not byte-identical published
serialization claims. Tests compare every physical moment, raw measurement
order, detector parity, and all four accumulated logical parities.

The Choi-state, signed-flow, CSS-rank/commutation, and deterministic-parity
completeness tests independently use Stim and elementary binary algebra.
They do not use the author's symbolic Pauli propagation as the oracle.
The signed `Stim.Circuit.has_flow` check is randomized (256 trials in the
installed version), not an exact symbolic proof. These checks do not establish
circuit distance, a threshold, or SI1000 benchmark fidelity.


The 12 `native_d*.stim` fixtures use the same external generator with
`gate_set="native-cz"`, d=4/8/12, X/Z, one/three rounds. They retain the author's
original unshifted supports. PECOS computes each affine constant from the signed
cycle maps, then tests it against the independent reference sample. Native
physical moments match exactly; PECOS Stim export adds a final synthetic MPAD
record to serialize the explicit XOR constants without adding a physical gate.
